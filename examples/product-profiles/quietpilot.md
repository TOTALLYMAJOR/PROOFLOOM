# QuietPilot

## Archetype

Operational control system

## Core promise

Promise -> Prepare -> Deliver

## Design psychology

- operational intelligence
- command
- readiness
- calm authority

## Canonical lifecycle

Inquiry -> Lead -> Quote -> Proposal -> Acceptance -> Payment -> Job -> Staffing -> Inventory -> Readiness -> Delivery

## UX implications

- controlled density is acceptable
- blockers, state, dependencies, and next action must dominate
- avoid presenting modules as an undifferentiated grid
