# UX Models

The canonical UX instructions remain in `skills/ux-architect/`.

Every contract identifies actor, object, goal, decision, state, blocker, authority, and primary action. Responsive review asks what remains, collapses, defers, becomes sticky, or changes priority; mobile is not treated as compressed desktop.

The V2 fixture demonstrates this by moving the evidence receipt before the deeper pipeline below 900px while preserving the same authority and action.
