# Design Language

The canonical operating instructions remain in `skills/design-language/` and its references. Product-specific defaults remain data-backed under `design_intelligence/data/product_profiles/` and `examples/product-profiles/`.

V2 does not introduce a second visual system. It adds retrieval and verification around the existing authority order:

1. Product behavior and requirements
2. Repository governance and design documentation
3. Existing tokens and primitives
4. Validated design decisions
5. References and general convention
6. Agent preference

Substantial work must retrieve relevant memory and bind a design contract before implementation.
