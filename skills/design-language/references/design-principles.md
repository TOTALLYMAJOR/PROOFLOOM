# Design Principles

- Translate abstract product traits into visible consequences.
- Typography should establish hierarchy before decoration.
- Color roles are distinct: brand, interaction, semantic, status, surface, emphasis, and data.
- Geometry must feel intentional: spacing, radius, borders, dividers, and elevation should reinforce identity.
- Surface hierarchy should be explicit from application to control; avoid card-within-card repetition by default.
- Reuse current tokens and primitives before introducing new ones.
- When a repository already has strong UI patterns, preserve and sharpen them instead of replacing them with a new style system.
